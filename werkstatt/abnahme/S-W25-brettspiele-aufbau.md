# Abnahme am Handy: Aufbau der Brettspiele (S-W25)

Link: https://memocan81735.github.io/brettspiele/ . Je Schritt abhaken oder Befund notieren.

| Schritt | Was du tust | Was du sehen solltest | ok? |
| --- | --- | --- | --- |
| U-1 | Brettspiele öffnen (beim ersten Mal) | Überschrift "Brettspiele" und sieben Kacheln mit Bild und Namen, alle ohne Scrollen | |
| U-2 | Auf "Mühle" tippen | das Spiel erscheint sofort, oben "‹ Spiele", der Name "Mühle" und der Tonknopf | |
| U-3 | Auf "‹ Spiele" tippen, danach ein Spiel öffnen und die Zurück-Geste des Handys benutzen | beide Male erscheint die Auswahl, die Kachel des letzten Spiels trägt "Weiterspielen" | |
| U-4 | In einem Spiel zwei Züge machen, Seite schließen und neu öffnen | dasselbe Spiel öffnet sich direkt, die Partie steht wie verlassen | |
| U-5 | Nacheinander alle Spiele öffnen | überall dieselbe Reihenfolge: Statuszeile, Brett, Aktionen, Spielmodus, Optionen, Statistik; die Kopfzeile springt nicht | |
| U-6 | In jedem Spiel nach dem Öffnen nicht scrollen | Statuszeile, Brett und die Zeile mit "Neu starten", "Zug zurück", "Tipp" sind zu sehen | |
| U-7 | Knöpfe und Felder mit dem Daumen antippen, auch "?" bei Mühle und "Statistik zurücksetzen" | kein Fehltipp, jeder Knopf trägt ein Symbol | |
| U-8 | Schach öffnen und nach unten scrollen, danach Mangala | der Hinweis zum Schach-Computer steht nur bei Schach und Schachschule, der Satz zum Datenschutz überall | |
| U-9 | Handy quer halten, Schach, Mühle und Vier gewinnt öffnen, auch mit eingeblendeter Adressleiste | Brett links und vollständig sichtbar, Knöpfe rechts daneben, nichts ist unten abgeschnitten | |
| U-10 | Quer zurück zur Auswahl | alle Kacheln ohne Scrollen sichtbar | |
